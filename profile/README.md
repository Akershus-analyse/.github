# Akershus-analyse

Her deler analysemiljøet i Akershus fylkeskommune skript, verktøy og tabeller fra arbeidet vårt med statistikk og analyse. Alt du finner her, er fritt til gjenbruk. Vi blir glade for innspill og forbedringer.

## Hva du finner her

### microdata.no

| Repo | Innhold |
|---|---|
| [microdata-skript](https://github.com/Akershus-analyse/microdata-skript) | Analyseskript for microdata.no, ordnet etter tema |
| [microdata-hjelper](https://github.com/Akershus-analyse/microdata-hjelper) | Claude-skill som hjelper med å skrive og feilsøke microdata-skript |

### Data

| Repo | Innhold |
|---|---|
| [data-koblingstabeller](https://github.com/Akershus-analyse/data-koblingstabeller) | Omkodinger og grupperinger, f.eks. kommuneendringer, grunnkrets til bydel og aldersgrupper |

### Kode

| Repo | Innhold |
|---|---|
| [kodesnutter](https://github.com/Akershus-analyse/kodesnutter) | Små, gjenbrukbare biter i DAX, Power Query (M), Python, R og SQL |

## Konvensjoner

- **Navn på repoer:** Prefikset viser hva repoet handler om, f.eks. `microdata-`, `data-` og `pbi-`.
- **Tabeller:** Lagres som `.tsv`, altså tabulatorseparert, i UTF-8 med desimalkomma. GitHub viser dem som tabeller. Les dem inn med tabulator som skilletegn og komma som desimaltegn.
- **Microdata:** Vi deler bare skript, aldri resultater eller tall fra kjøringer.
